# 🪞 推妖镜 BotZapper

> 照妖镜一照，妖怪现形；你亲手一点，世界清静。

识别 X (Twitter) 评论区垃圾账号——黄推引流、钓鱼、兼职刷单、金融诈骗——黄色高亮标注，并提供**一键原生拉黑**的 Chrome 浏览器扩展。

产品与功能设计见 [DESIGN.md](DESIGN.md)（基于福滤娃 FeedSieve 的全维度复盘提炼）。

## 功能（v0.1 MVP）

- **本地识别引擎**：评分制词库匹配，含全角字符归一化、零宽字符检测、插空混淆对抗（`看.我.主.页` 一样现形）。识别阶段**零网络请求**。
- **高亮标注**：命中评论黄框标注 + 妖气值 + 命中原因（如「主页导流、色情引流」）。
- **一键拉黑**：单条「拉黑」按钮；左下角徽章显示「本页妖怪 N 个」，支持一键清理整页。
- **原生拉黑**：调用 X 官方拉黑接口，服务端生效、全端同步——不是前端眼不见为净。
- **防风控**：拉黑请求全浏览器**串行队列**，相邻请求随机延迟 800–2000ms，HTTP 429 立即熔断暂停 10 分钟，每日上限默认 50 次。
- **防误伤**：宁可漏掉两个，绝不错杀一个。当前登录用户强制豁免；点「误判」的账号进入永久白名单；宽松/标准/严格三档灵敏度（默认标准档：单词强信号或双中信号组合才标注）。
- **零数据收集**：无远端上报、无统计埋点，所有数据只存在你的浏览器本地。

## 安装（开发者模式）

1. 下载/克隆本仓库；
2. 打开 Chrome，访问 `chrome://extensions`；
3. 右上角打开「开发者模式」；
4. 点「加载已解压的扩展程序」，选择本仓库根目录（含 `manifest.json`）；
5. 刷新 x.com，左下角出现「🪞 推妖镜」徽章即安装成功。

## 使用

- 可疑评论会被黄框标注，框内点红色「拉黑」= 调用官方接口原生拉黑该账号；
- 左下角徽章显示当前页面捕获数量，点「一键清理」批量拉黑全页妖怪；
- 点「误判」：立即恢复正常显示，该账号进入永久白名单；
- 点工具栏推妖镜图标打开弹窗：总开关、灵敏度、今日额度、白名单管理、队列状态。

## 它是如何调用拉黑接口的？

拉黑请求由扩展的 service worker 从**你的浏览器、用你自己的登录会话**发出，语义完全等价于你本人在网页上点「拉黑」按钮——插件只是替你省了「三点菜单 → 拉黑 → 确认」的四步操作。频率上做了拟人化限速与熔断保护（见上），因此**不会**高频请求，也不会读取你的时间线数据。

## 开发

零依赖、无构建步骤，纯 Manifest V3 原生 JS。

```
node --test "tests/*.test.mjs"   # 跑识别引擎单元测试（16 例）
python3 scripts/gen-icons.py     # 重新生成图标（需 Pillow）
```

打开 `test/fixture.html`（模拟 X DOM + chrome API mock）可在不登录 X 的情况下调试识别与 UI 全流程；`test/fixture.html?autoblock=1` 会自动演示拉黑状态流转。

```
src/
├── core/          # 识别引擎（纯函数，浏览器/Node 共用）
│   ├── normalize.js   # 全角/零宽/插空归一化
│   ├── rules.js       # 公共词库（评分制，全文公开）
│   ├── detector.js    # 评分引擎
│   └── storage.js     # chrome.storage 封装
├── content/       # 内容脚本
│   ├── ui.js          # 高亮/按钮/浮动徽章
│   └── main.js        # DOM 监听与状态判定
├── background/    # service worker：串行拉黑队列 + 熔断
└── popup/         # 设置面板
```
